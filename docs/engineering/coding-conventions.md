# 编码约定（Coding Conventions）

本文档归纳**从现有代码中观察到的**约定，供保持一致性。🔶 多为归纳推断，非明文规范。

## 通用

- ✅ 全栈时区 Asia/Seoul；时间一律 `timestamptz`（DB）/ `OffsetDateTime`（Java）。
- ✅ 标识符跨层一致：DB `snake_case`，Java `camelCase`，API 路径 `snake_case`（如 `/api/v1/cctv_cameras`、`/detection_events`）。
- 🔶 注释与领域措辞多为韩文（项目源自韩国幼儿园场景）。

## 后端（Java / Spring）

| 主题 | 约定 |
| --- | --- |
| 包结构 | 按层划分：`controller/service/repository/entity/dto/vo/mapper/type/security/config` |
| 依赖注入 | 构造器注入：`@RequiredArgsConstructor` + `private final` |
| 传输模型 | 入 `DTO`、出 `VO`，不暴露 `Entity`；转换用 MapStruct |
| 命名 | `XxxController`/`XxxService`/`XxxRepository`/`XxxCreateDTO`/`XxxUpdateDTO`/`XxxVO`/`XxxMapper` |
| 路由 | `@RequestMapping("/api/v1/<resource>")`，资源名 `snake_case` 复数 |
| 枚举 | `type/` 包，与 PG enum 取值一一对应 |
| 事务 | Service 上 `@Transactional`（只读查询用 `readOnly = true`） |
| 注入配置 | 用 `@Value("${...}")` 读 `application.yml`（其值来自环境变量） |

## 前端（TypeScript / Next.js）

| 主题 | 约定 |
| --- | --- |
| 路由 | App Router，路由组用 `(group)`；页面在 `app/<feature>/` |
| 组件 | 业务组件按域放 `components/<domain>/`；通用 UI 放 `components/shared/ui/` |
| API 调用 | 统一经 `services/apis/apiClient.ts`，每域一个 `*.api.ts` |
| 类型 | 领域类型放 `types/`；命名如 `child.ts`、`detectionEvents.ts` |
| 状态 | Redux Toolkit slice 放 `store/slices/`，hooks 经 `store/hook.ts` |

## AI（Python）

| 主题 | 约定 |
| --- | --- |
| 包根 | `src/ai_app/`，运行需 `PYTHONPATH=src` |
| 分层 | `datasets/ models/ inference/ serving/ training/ utils/` |
| 入口 | 可执行脚本放 `scripts/`，库代码放 `src/ai_app/` |
| 配置 | 环境变量（`AI_MODEL_DIR` 等）+ `serving/deps.py` 的 `ServiceSettings` |
| 数据模型 | 用 `@dataclass(frozen=True)`（如 `PredictionResult`）；API schema 用 Pydantic（`serving/schemas.py`） |

## 数据库

- ✅ Schema 以 DBML 为源（`db/dbml/schema.dbml` → `dbml2sql`）。
- ✅ 主键 `BIGINT GENERATED BY DEFAULT AS IDENTITY`。
- ✅ 多租户表带 `kindergarten_id` 并入复合唯一键/外键。
- ✅ 通用状态用 `status_enum`；关系/分配表带 `start_*`/`end_*` 时间区间。
